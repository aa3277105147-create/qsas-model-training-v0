# QSAS v0：量子模拟器选择模型

根据电路的统计特征，为每个候选模拟器预测 600 秒内跑完的概率 **P** 和成功时的总时间 **T**。在满足适用规则的候选中，选择 `T + (1 − P) × 600` 最小的模拟器。

## 文件

| 路径 | 内容 |
| --- | --- |
| `train_v0.py` | 特征提取、训练、交叉验证和模型保存 |
| `requirements.txt` | 训练所需的依赖版本 |
| `data/training-audited-600s.csv` | 完整训练表，9352 条记录 |
| `model-v0/` | 13 个已训练模型及 `meta.json` |
| `evaluation/report.json` | v0 的整体、分宽度段及各模型评估指标 |
| `evaluation/choices-*.csv` | 每个测试电路的选择、实际耗时及最快候选 |
| `evaluation/predictions-*.csv` | 每个测试电路、候选对应的 P、T 和实际结果 |
| `evaluation/family-*.csv` | 按电路族汇总的表现 |

## 重新训练

使用 Python 3.11，在本目录执行：

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python train_v0.py data outputs/v0
```

程序先执行两种交叉验证，再使用全部有效数据训练最终模型。新模型写入 `outputs/v0/model-v0/`，新评估结果写入 `outputs/v0/`。macOS 如缺少 OpenMP 运行库，可先安装 `libomp`。

## 数据与训练

一条记录对应一个“电路、模拟器”的运行结果。去掉生成失败的电路后，剩余 8981 条记录，覆盖 31 个电路族、1295 个电路，宽度为 2–1000 比特。训练表保留所有原始记录；移除了机器绑定字段 `cpuset`、`numa_node`，其余字段和数值保持不变。

| 运行结果 | 条数 | P 的标签与权重 | T 的训练 |
| --- | ---: | --- | --- |
| 成功 | 4537 | 1，权重 1 | 使用 `log10(wall_s)` |
| 超时或内存不足 | 275 | 0，权重 1 | 不使用 |
| 推断不可行 | 2082 | 0，权重 0.5 | 不使用 |
| 预先判定不支持 | 2086 | 不使用 | 不使用 |
| 其他错误 | 1 | 不使用 | 不使用 |

`wall_s` 是包含容器启动、库导入、电路读取与模拟在内的总时间。推断不可行来自实验中的停止规则：同一电路族、同一模拟器连续两个宽度失败后，跳过后续更大宽度。单调约束用于模型训练，不用于生成这些标签。

输入依次为 `log2(n)`、`log10(g+1)`、`log10(d+1)`、是否 Clifford（0/1）、`log10(c+1)`、`log10(g/n+1)`、`log10(d/n+1)`、`c/(g+1)`。其中 n 为比特数，g 为编译后门数，d 为编译后深度，c 为沿比特顺序所有切口中最大的跨切口两比特门数。电路编译到 `{rz, sx, x, cx}`，优化级别 1，编译种子 11；小宽度一致性检查失败时使用级别 0。电路族名称只用于划分评估数据，不作为输入特征。

P 使用 LightGBM 分类器，T 使用 LightGBM 回归器，输出后通过 `10 ** prediction` 还原为秒。每个模型使用 300 棵树、学习率 0.05、最多 15 个叶子、`min_child_samples=10`，随机种子为 0。宽度、门数、深度和最大切割门数对应的特征施加单调约束：P 单调不增，T 单调不减。

## 候选与模型文件

| 编号 | 模拟器 | 适用规则 |
| --- | --- | --- |
| c1 | Aer statevector | n ≤ 34 |
| c2 | Aer MPS | 无额外宽度限制 |
| c3 | DDSIM | 无额外宽度限制 |
| c3b | DDSIM hybrid | 无额外宽度限制 |
| c4 | Quimb MPS | 无额外宽度限制 |
| c5 | Qulacs | n ≤ 34 |
| stim | Stim | 仅 Clifford 电路 |

`*-ok.txt` 预测 P，`*-time.txt` 预测 `log10(T)`，均可通过 LightGBM 的 `Booster(model_file=...)` 加载。Stim 的有效训练样本全部成功，因此 P 固定为 1；共有 6 个分类器和 7 个回归器。`meta.json` 保存特征顺序、候选编号、适用规则和选择公式。所有适用候选的 P 均低于 0.3 时，仍返回分数最低的候选，并给出低把握标记。

## 已保存的评估结果

按电路划分数据，同一电路的不同模拟器记录不会分到训练集和测试集两侧。留一族评估使用 31 折；随机评估使用 5 折。1281 个电路具备全部候选记录并参与评估；另外 14 个补点电路不计入评估。

| 评估方式 | 选中实际最快者 | 所选模拟器失败数 | 总耗时 / 每次选最快的总耗时 |
| --- | ---: | ---: | ---: |
| 留一族 | 72.8% | 13 | 1.593 |
| 随机 5 折 | 81.4% | 2 | 1.084 |

上表统计 1183 个至少有一个候选成功的电路；另外 98 个电路所有候选均未成功。失败的选择按 600 秒计入代价。`model-v0/` 与 `evaluation/` 保存既有 v0 的模型和结果，评估报告仅保留 v0 项。

## 基础硬件与运行条件

基准数据在 x86_64 CPU 环境采集，处理器为 Intel Xeon Platinum 8153（2.00 GHz）。每个模拟任务使用 16 个物理核心、32 个线程，常规内存限额 32 GiB，大内存档 512 GiB；每次运行 1 shot，时限 600 秒。Aer MPS 与 Quimb MPS 使用零截断阈值。时间预测对应上述条件，运行环境改变时需重新验证。
